# JippGra

JippGra is a simple aim-training game project created with C++ and SFML.

This is one of my first projects, so the project structure and code organization still leave a lot to be desired.

## What it does

- Opens a fullscreen game window
- Lets you start a game from a menu
- Includes settings for target size, number of targets, time, and skin
- Shows your score at the end

## Tech

- C++
- SFML
- Visual Studio project files (`.vcxproj`)

## Note

This repository is mainly a learning project and an early step in my programming journey.
